## Ideia-chave
Para analisar a viabilidade econômica comparativa entre as fontes de energia solar e eólica, calcula-se o fluxo de caixa gerado por cada alternativa frente ao consumo atual de $12\,000\text{ kWh/mês}$ ao custo de $\text{R\$ } 0{,}50/\text{kWh}$ (gasto mensal de $\text{R\$ } 6\,000{,}00$):
- Na **opção solar**, os painéis fotovoltaicos geram $10\,000\text{ kWh/mês}$, gerando uma economia de $10\,000 \times 0{,}50 = \text{R\$ } 5\,000{,}00$ por mês, o que totaliza $\text{R\$ } 60\,000{,}00$ por ano. O custo inicial de instalação de $\text{R\$ } 120\,000{,}00$ é quitado (*payback*) em exatamente $\frac{120\,000}{60\,000} = 2\text{ anos}$ de uso.
- Na **opção eólica**, a contratação da cooperativa custa $\text{R\$ } 0{,}30/\text{kWh}$ no primeiro ano com reajuste composto de $5\%$ ao ano, de modo que a economia anual diminui a cada ano, chegando no 5º ano a um valor inferior a $\text{R\$ } 20\,000{,}00/\text{ano}$.
Portanto, a alternativa economicamente correta é a **D**.

## Resolução passo a passo
**Passo 1 — Situação de consumo atual da empresa.**
- Consumo mensal: $C = 12\,000\text{ kWh}$.
- Tarifa convencional da concessionária: $T_0 = \text{R\$ } 0{,}50/\text{kWh}$.
- Gasto mensal atual: $G_{\text{atual}} = 12\,000 \times 0{,}50 = \text{R\$ } 6\,000{,}00/\text{mês}$.
- Gasto anual atual: $12 \times 6\,000 = \text{R\$ } 72\,000{,}00/\text{ano}$.

**Passo 2 — Análise da energia solar.**
- Capacidade de geração dos painéis: $10\,000\text{ kWh/mês}$.
- Como a empresa consome $12\,000\text{ kWh}$, ela continuará adquirindo apenas o excedente de $2\,000\text{ kWh}$ da rede:
  $$G_{\text{solar}} = 2\,000 \times 0{,}50 = \text{R\$ } 1\,000{,}00/\text{mês}$$
- Economia mensal gerada pela energia solar:
  $$\Delta E_{\text{mês}} = 6\,000 - 1\,000 = \text{R\$ } 5\,000{,}00/\text{mês}$$
  (ou diretamente: $10\,000\text{ kWh} \times \text{R\$ } 0{,}50/\text{kWh} = \text{R\$ } 5\,000{,}00/\text{mês}$).
- Economia anual:
  $$\Delta E_{\text{ano}} = 12 \times 5\,000 = \text{R\$ } 60\,000{,}00/\text{ano}$$
- Tempo de retorno (*payback* simples) sobre o investimento inicial de $\text{R\$ } 120\,000{,}00$:
  $$t = \frac{\text{Custo de instalação}}{\text{Economia anual}} = \frac{120\,000}{60\,000} = 2\text{ anos}$$
  Portanto, o custo inicial é quitado exatamente com a economia obtida em **dois anos de uso**.

**Passo 3 — Verificação da energia eólica e refutação das demais afirmativas.**
- A energia eólica é contratada a $\text{R\$ } 0{,}30/\text{kWh}$ com reajuste anual de $5\%$ ($i = 0{,}05$).
- Ano 1: Tarifa eólica $= 0{,}30$. Economia mensal $= 12\,000 \times (0{,}50 - 0{,}30) = \text{R\$ } 2\,400{,}00/\text{mês}$, totalizando $\text{R\$ } 28\,800{,}00/\text{ano}$.
  Observe que a economia mensal da eólica ($\text{R\$ } 2\,400{,}00$) é consideravelmente inferior à da solar ($\text{R\$ } 5\,000{,}00$).
- No 5º ano (após 4 reajustes sucessivos), utilizando o dado $(1{,}05)^4 \approx 1{,}22$:
  $$\text{Tarifa}_{\text{ano 5}} = 0{,}30 \times 1{,}22 = \text{R\$ } 0{,}366/\text{kWh}$$
  Economia no ano 5:
  $$\Delta E_{\text{ano 5}} = 12\,000 \times 12 \times (0{,}50 - 0{,}366) = 144\,000 \times 0{,}134 = \text{R\$ } 19\,296{,}00$$
  Como $\text{R\$ } 19\,296{,}00 < \text{R\$ } 20\,000{,}00$, a economia **não** é de "mais de $\text{R\$ } 20\,000{,}00$ ao ano nos primeiros cinco anos".

## Análise das alternativas
- **A — incorreta.** No 5º ano, com a tarifa eólica reajustada para $\text{R\$ } 0{,}366/\text{kWh}$, a economia anual cai para $\text{R\$ } 19\,296{,}00$, sendo, portanto, estritamente inferior a $\text{R\$ } 20\,000{,}00$.
- **B — incorreta.** Desconsiderando os custos de implantação, a energia solar gera uma economia mensal de $\text{R\$ } 5\,000{,}00$, enquanto a eólica gera apenas $\text{R\$ } 2\,400{,}00$ no primeiro ano (e decresce nos seguintes). A solar gera maior economia mensal.
- **C — incorreta.** Quitado o custo inicial, a economia mensal é de $\frac{10\,000}{12\,000} \approx 83{,}33\%$ da fatura (ou $5\,000 / 6\,000 \approx 83{,}33\%$), e não $75\%$.
- **D — correta.** A energia solar é a mais viável porque o investimento inicial de $\text{R\$ } 120\,000{,}00$ é integralmente amortizado em dois anos, graças à economia anual de $\text{R\$ } 60\,000{,}00$ ($2 \times 60\,000 = 120\,000$).

## Conceitos envolvidos
- **Matemática Financeira:** análise de investimentos, tempo de retorno (*payback* simples) e juros compostos com reajustes sucessivos.
- **Educação Financeira e Sustentabilidade:** tomada de decisão baseada em modelagem matemática aplicada a fontes de energia renováveis.

## Dica de prova
Calcule rapidamente a economia anual da opção solar: $10\,000 \times 0{,}50 \times 12 = \text{R\$ } 60\,000{,}00$. Dividindo o custo de $\text{R\$ } 120\,000{,}00$ por $60\,000$, obtém-se $2$ anos exatos! Isso leva diretamente à alternativa D sem necessidade de cálculos extensos de juros compostos.
