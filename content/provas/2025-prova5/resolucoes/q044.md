## Ideia-chave
A média aritmética simples de um conjunto de valores é dada pelo quociente entre a soma de todos os termos e o número total de observações: $\bar{x} = \frac{1}{n}\sum_{i=1}^n x_i$. Uma propriedade algébrica basilar da média é que a inclusão de um novo dado com valor estritamente menor do que a média preexistente ($x_{n+1} < \bar{x}$) acarreta necessariamente a redução do valor da média final ($\bar{x}_{\text{novo}} < \bar{x}$). Como a média original de tempo em jogos dos $11$ estudantes é igual a $4$ horas, a hipotética inclusão de um 12º estudante com uso diário de $3$ horas ($3 < 4$) faz com que a nova média seja $\frac{44 + 3}{12} = \frac{47}{12} \approx 3{,}917\text{ h}$, diminuindo o valor da média da turma.

## Resolução passo a passo
**Passo 1 — Tabulação e cálculo dos parâmetros originais da distribuição.**
Convertendo os tempos dos $11$ estudantes para horas decimais:
- Estudante 1: $4\text{ h} = 4{,}00\text{ h}$
- Estudante 2: $4\text{ h }30\text{ min} = 4{,}50\text{ h}$
- Estudante 3: $3\text{ h }15\text{ min} = 3{,}25\text{ h}$
- Estudante 4: $5\text{ h} = 5{,}00\text{ h}$
- Estudante 5: $3\text{ h }15\text{ min} = 3{,}25\text{ h}$
- Estudante 6: $6\text{ h }15\text{ min} = 6{,}25\text{ h}$
- Estudante 7: $4\text{ h }15\text{ min} = 4{,}25\text{ h}$
- Estudante 8: $3\text{ h} = 3{,}00\text{ h}$
- Estudante 9: $2\text{ h} = 2{,}00\text{ h}$
- Estudante 10: $5\text{ h} = 5{,}00\text{ h}$
- Estudante 11: $3\text{ h }30\text{ min} = 3{,}50\text{ h}$

1. **Soma dos tempos:**
   $$\sum_{i=1}^{11} x_i = 4{,}00 + 4{,}50 + 3{,}25 + 5{,}00 + 3{,}25 + 6{,}25 + 4{,}25 + 3{,}00 + 2{,}00 + 5{,}00 + 3{,}50 = 44{,}00\text{ h}$$
2. **Média aritmética original:**
   $$\bar{x} = \frac{44{,}00}{11} = 4{,}00\text{ h}$$
3. **Rol ordenado e Mediana:**
   Organizando os $11$ valores em ordem crescente:
   $$2{,}00 \;; 3{,}00 \;; 3{,}25 \;; 3{,}25 \;; 3{,}50 \;; \mathbf{4{,}00} \;; 4{,}25 \;; 4{,}50 \;; 5{,}00 \;; 5{,}00 \;; 6{,}25$$
   Como $n = 11$ é ímpar, o elemento central é o 6º termo:
   $$\text{Mediana} = x_{(6)} = 4{,}00\text{ h}$$
Ambos os parâmetros são exatamente iguais a $4$ horas, confirmando os dados fornecidos pelo docente.

**Passo 2 — Análise da Hipótese da alternativa D (inclusão de um novo estudante com 3 horas).**
Se mais um estudante participar da pesquisa com tempo $x_{12} = 3\text{ h}$:
- O número total de observações passa a ser $n' = 11 + 1 = 12$.
- A nova soma dos tempos será:
  $$\sum_{i=1}^{12} x_i = 44 + 3 = 47\text{ h}$$
- A nova média da distribuição será:
  $$\bar{x}_{\text{novo}} = \frac{47}{12} \approx 3{,}917\text{ h} \quad (3\text{ h }55\text{ min})$$
Como $3{,}917\text{ h} < 4{,}00\text{ h}$, **o valor da média diminuiria**.
Em termos teóricos gerais:
$$\bar{x}_{\text{novo}} - \bar{x} = \frac{n \bar{x} + x_{\text{novo}}}{n + 1} - \bar{x} = \frac{x_{\text{novo}} - \bar{x}}{n + 1}$$
Como $x_{\text{novo}} = 3 < \bar{x} = 4$, a diferença é estritamente negativa, garantindo a redução da média.

**Passo 3 — Refutação analítica das demais alternativas.**
- **Alternativa A:** Se retirarmos o estudante 8 ($x = 3{,}00\text{ h}$), restam $10$ dados:
  $$2{,}00 \;; 3{,}25 \;; 3{,}25 \;; 3{,}50 \;; \mathbf{4{,}00} \;; \mathbf{4{,}25} \;; 4{,}50 \;; 5{,}00 \;; 5{,}00 \;; 6{,}25$$
  A nova mediana seria a média entre o 5º e o 6º termos:
  $$\text{Mediana}' = \frac{4{,}00 + 4{,}25}{2} = 4{,}125\text{ h}$$
  Portanto, a mediana aumentaria (de $4{,}00\text{ h}$ para $4{,}125\text{ h}$), e não diminuiria.
- **Alternativa B:** Pela propriedade da linearidade da média, se cada valor for acrescido de $c = 1\text{ h}$, a nova média sofrerá o mesmo acréscimo: $\bar{x}' = \bar{x} + 1 = 5{,}00\text{ h}$, logo ela se altera.
- **Alternativa C:** Somar $2\text{ h}$ a todos os dados desloca toda a distribuição para a direita, elevando a mediana para $4{,}00 + 2{,}00 = 6{,}00\text{ h}$, logo ela não continua a mesma.

## Análise das alternativas
- **A — incorreta.** Ao excluir um valor inferior à mediana ($3{,}00 < 4{,}00$), a mediana da distribuição resultante aumenta para $4{,}125\text{ h}$.
- **B — incorreta.** Somar uma constante a todos os elementos translada a média na mesma magnitude ($+1\text{ h}$).
- **C — incorreta.** Somar $2\text{ horas}$ a cada elemento aumenta a mediana em $2\text{ horas}$.
- **D — correta.** Enuncia perfeitamente que a inclusão de um estudante com tempo diário de $3\text{ horas}$ (menor que a média atual de $4\text{ horas}$) acarreta a diminuição do valor da média.

## Conceitos envolvidos
- **Estatística Descritiva Básica:** média aritmética, mediana de variáveis quantitativas contínuas/discretas e rol ordenado.
- **Propriedades das Medidas de Posição Central:** sensibilidade da média a novos dados e propriedades de translação aditiva ($\bar{x}_{x+c} = \bar{x}_x + c$).

## Dica de prova
Regra de ouro das médias: adicionar um elemento menor que a média sempre puxa a média para baixo; adicionar um elemento maior que a média sempre puxa a média para cima; adicionar um elemento igual à média mantém a média inalterada.
