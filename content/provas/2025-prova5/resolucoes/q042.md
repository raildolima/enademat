## Ideia-chave
O clássico quebra-cabeça da **Torre de Hanói** com $n$ discos e três hastes obedece a uma lógica indutiva estrita: para transferir uma torre de $n+1$ discos de uma haste de origem para uma haste de destino, deve-se primeiro transferir a subtorre dos $n$ discos menores para a haste auxiliar ($f_n$ movimentos), mover o disco maior restante diretamente para a haste de destino ($1$ movimento) e, em seguida, transferir novamente os $n$ discos da haste auxiliar para sobre o maior na haste de destino ($f_n$ movimentos). Assim, a quantidade mínima de movimentos satisfaz a relação de recorrência linear de primeira ordem:
$$f_{n+1} = 2f_n + 1, \quad \text{com } f_1 = 1$$

## Resolução passo a passo
**Passo 1 — Descrição do problema e das regras de movimentação.**
A Torre de Hanói é composta por $3$ hastes verticais e $n$ discos de diâmetros distintos. As regras são:
1. Apenas um disco pode ser movido por vez.
2. Nenhum disco maior pode ser colocado sobre um disco menor.
3. O objetivo é transferir todos os discos da haste inicial para uma haste de destino.

**Passo 2 — Dedução estrutural da relação de recorrência.**
Seja $f_n$ o número mínimo de movimentos necessários para transferir uma torre de $n$ discos.
Para transferir uma torre de $n+1$ discos:
- O maior disco (o disco inferior da pilha) só pode ser movido se todos os $n$ discos superiores tiverem sido removidos e acumulados em uma haste intermediária (a haste auxiliar). Por definição da minimalidade, essa etapa requer no mínimo $f_n$ movimentos.
- Uma vez desobstruído, o maior disco é transferido diretamente da haste de origem para a haste de destino, exigindo exatamente $1$ movimento.
- Por fim, a torre com os $n$ discos que está temporariamente na haste auxiliar deve ser integralmente movida para a haste de destino, repousando sobre o disco maior. Como o disco maior é maior que todos os outros, sua presença no fundo não restringe as regras para os demais; portanto, essa etapa requer novamente $f_n$ movimentos.

Somando os movimentos mínimos necessários nas três etapas consecutivas:
$$f_{n+1} = f_n + 1 + f_n = 2f_n + 1$$

**Passo 3 — Validação com os dados experimentais fornecidos.**
Com a condição inicial $f_1 = 1$, calculam-se os termos sucessivos pela recorrência:
- Para $n = 1$: $f_2 = 2f_1 + 1 = 2(1) + 1 = 3$ movimentos.
- Para $n = 2$: $f_3 = 2f_2 + 1 = 2(3) + 1 = 7$ movimentos.
- Para $n = 3$: $f_4 = 2f_3 + 1 = 2(7) + 1 = 15$ movimentos.
- Para $n = 4$: $f_5 = 2f_4 + 1 = 2(15) + 1 = 31$ movimentos.
Os valores $1, 3, 7, 15$ coincidem com total exatidão com os dados observados pelos estudantes descritos no texto.

**Passo 4 — Resolução analítica da recorrência (forma fechada).**
A equação de recorrência $f_{n+1} = 2f_n + 1$ pode ser resolvida somando $1$ em ambos os membros:
$$f_{n+1} + 1 = 2(f_n + 1)$$
Definindo uma sequência auxiliar $g_n = f_n + 1$:
$$g_{n+1} = 2g_n \implies g_n = g_1 \cdot 2^{n-1}$$
Como $g_1 = f_1 + 1 = 1 + 1 = 2$, temos:
$$g_n = 2 \cdot 2^{n-1} = 2^n \implies f_n = 2^n - 1$$
Dessa forma, $f_{n+1} = 2^{n+1} - 1 = 2(2^n - 1) + 1 = 2f_n + 1$, confirmando o modelo.

## Análise das alternativas
- **A — incorreta.** A relação $f_{n+1} = 2f_n - 1$ geraria $f_2 = 2(1) - 1 = 1$, divergindo imediatamente do valor empírico $f_2 = 3$.
- **B — incorreta.** Embora algebricamente $f_{n+1} - f_n = (2^{n+1} - 1) - (2^n - 1) = 2^n$, essa relação insere uma dependência externa não homogênea na potência $2^n$, enquanto a representação clássica do modelo recursivo da ação de movimentação física deduzida do problema é expressa diretamente em termos de $f_n$ pela equação $2f_n + 1$.
- **C — correta.** Representa rigorosamente o modelo recursivo derivado da decomposição da tarefa: mover os $n$ discos, mover o disco basal e mover novamente os $n$ discos ($f_{n+1} = 2f_n + 1$).
- **D — incorreta.** A expressão $f_{n+1} = f_n + n + 1$ geraria uma progressão de segunda ordem com crescimento quadrático $\frac{n(n+1)}{2}$, inadequada para o crescimento exponencial intrínseco da Torre de Hanói.

## Dica de prova
Guarde a dedução física da Torre de Hanói: para passar $n+1$ discos, você move $n$ discos para o pino auxiliar ($f_n$), passa o maior para o destino ($1$) e move os $n$ discos por cima dele ($f_n$). Isso dá imediatamente $f_n + 1 + f_n = 2f_n + 1$.
